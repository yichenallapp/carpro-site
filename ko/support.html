자동차 장부 지원

문제가 있거나 제안이 있다면 먼저 아래 자주 묻는 질문을 확인하세요. 답을 찾지 못하면 메일로 문의해 주세요.

데이터는 어디에 저장되나요?

기본적으로 iPhone에만 저장됩니다. 설정 → 동기화 방식에서 iCloud 또는 내 Google 스프레드시트에 동기화할 수 있고, 동기화하지 않아도 됩니다. 앱을 삭제하면 휴대폰의 데이터도 삭제되므로 보관하려면 먼저 동기화를 켜세요.

기기를 바꿀 때 데이터를 옮기려면?

이전 iPhone의 설정 → 동기화 방식에서 iCloud Drive(또는 Google 스프레드시트)를 선택하고 동기화가 끝날 때까지 기다립니다. 새 iPhone에 앱을 설치하고 같은 Apple ID로 로그인한 뒤 똑같이 iCloud Drive를 선택하세요. 번호판이 같은 차량은 자동으로 하나로 합쳐지고 기록이 서로 보완됩니다.

무료 버전과 Pro는 무엇이 다른가요?

주유·지출 기록, 통계와 그래프, 단위와 통화, 다국어 지원은 계속 무료입니다. Pro(일회성 구매, 구독 아님)로 여러 대의 차와 동기화(iCloud, Google 스프레드시트)를 사용할 수 있습니다. Pro가 없는 동안 기록은 이 iPhone에만 저장되며, 나중에 Pro를 잠금 해제하면 자동으로 전송되므로 사라지지 않습니다.

구매 복원이나 프로모션 코드는 어떻게 쓰나요?

설정 → Pro에서 '구매 복원'을 누르면 구매 시 사용한 Apple ID로 복원됩니다. 프로모션 코드가 있다면 '프로모션 코드 사용'을 누르세요. 기기를 바꾸거나 앱을 다시 설치했을 때도 '구매 복원'을 사용합니다. 가족 공유가 켜져 있으면 가족도 사용할 수 있습니다.

Google 스프레드시트에 동기화하려면?

앱 안에 단계별 안내가 있습니다(처음 실행 시 환영 화면, 또는 설정 → 동기화 방식의 설정 가이드). 약 5분 걸립니다. 스프레드시트와 시트를 만들고, 앱이 제공하는 코드를 Apps Script에 붙여넣고, API 토큰을 생성하고, 웹 앱으로 배포한 뒤, URL과 토큰을 앱에 붙여넣습니다. 컴퓨터에서 하는 것을 권장합니다.

시트 이름과 머리글은 어떻게 짓나요?

번체 중국어, English, 간체 중국어 세 가지를 지원하며 한 스프레드시트에서는 하나를 골라 씁니다(영문은 대소문자 구분 없음). 영어 예시: Fuel, Car Wash, Supplies, Maintenance, Insurance. 앱의 가이드가 언어에 맞는 시트 이름과 복사할 수 있는 머리글을 보여 줍니다.

연결 테스트에서 unauthorized가 표시됩니다

토큰을 잘못 붙여넣었거나 불필요한 글자가 섞여 있습니다. 다시 복사하세요. setupToken을 다시 실행하면 새 토큰이 만들어지고 이전 토큰은 사용할 수 없게 됩니다.

시트를 찾을 수 없다고 나옵니다

시트 이름은 예시와 같아야 합니다(영문은 대소문자 구분 없음). 기존 데이터가 있는 스프레드시트도 그대로 쓸 수 있습니다.

단위와 통화를 바꿀 수 있나요?

네. 설정 → 단위 및 통화에서 바꿀 수 있습니다. 단위는 km/L, L/100km, mpg(미국·영국), 통화는 18종 중에서 선택합니다. 표시와 입력 방식만 바뀌며 데이터는 항상 킬로미터와 리터로 저장되고 이미 기록한 금액은 환산되지 않습니다.

여러 대의 차를 기록할 수 있나요?

네. 차량마다 번호판, 차종, 인수일, 인수 시 주행거리를 설정합니다. 홈·기록·통계 왼쪽 위의 번호판을 눌러 전환하세요. 여러 대가 하나의 스프레드시트를 공유할 수 있으며 '車牌'(번호판) 열로 구분됩니다.

평균 연비는 어떻게 계산하나요?

인수 시 주행거리(또는 주행거리가 처음 입력된 주유)부터 마지막 주행거리까지의 거리를 그동안의 주유량으로 나눕니다. 주유할 때 주행거리를 입력해야 계산됩니다. '최근 2회 주유' 연비로 전환할 수도 있습니다.

언어를 바꾸려면?

기본은 iPhone의 시스템 언어를 따릅니다. 설정 → 언어에서 직접 선택할 수 있으며 앱을 다시 열면 적용됩니다. 繁體中文, 简体中文, 日本語, 한국어, English를 지원합니다.
