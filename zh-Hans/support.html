爱车账本 支持

遇到问题或有建议，先看看下面的常见问题；找不到答案再来信。

我的数据存在哪里？

默认只存在你的 iPhone。你可以在“设置 → 同步方式”选择同步到 iCloud 或你自己的 Google 表格，也可以完全不同步。删除 App 会一并删除手机上的数据，所以想保留的话请先开启同步。

换手机时怎么把数据带过去？

旧手机到“设置 → 同步方式”选 iCloud Drive（或 Google 表格），等状态显示同步完成。新手机安装 App，用同一个 Apple ID 登录并同样选 iCloud Drive，车牌相同的车会自动合并，记录互相补齐。

要怎么同步到 Google 表格？

App 内有分步教程（第一次打开的欢迎页，或“设置 → 同步方式”旁的设置教程），约 5 分钟。步骤是：创建表格和分页、把 App 提供的代码粘贴到 Apps Script、生成 API Token、部署为 Web 应用，最后把网址和 Token 粘贴回 App。建议用电脑操作。

表格的分页和表头要怎么命名？

支持繁体中文、English、简体中文三种，同一份表任选一种（英文不分大小写）。例如简体：加油、洗车、用品、保养、保险。App 的教程页会按你的语言给出对应名称和可复制的表头。

测试连接显示 unauthorized

Token 贴错或带有多余文字，请重新复制一次。重新运行 setupToken 会生成新的 Token，旧的就失效。

显示找不到分页

分页名称要和范例一致（英文不分大小写）。已有旧数据的表格也可以直接用。

可以改单位和币别吗？

可以，到“设置 → 单位与币别”。单位支持 km／L、L/100km、mpg（美制、英制），币别有 18 种。这只改变显示和输入方式：数据一律以公里和升保存，已记录的金额不会被换算。

可以记录多辆车吗？

可以。每辆车有自己的车牌、车型、提车日期和提车里程；在首页、记录、统计左上角的车牌点一下即可切换。多辆车可以共用同一份表格，用“车牌”列区分。

平均油耗是怎么算的？

用提车里程（或第一笔有里程的加油）到最后一笔里程的距离，除以期间加的油量。加油时填了里程才算得出来；也可以切换成“最近两次加油”的油耗。

怎么切换语言？

默认跟随 iPhone 的系统语言，也可以在“设置 → 语言”手动选择，重新打开 App 后生效。支持繁體中文、简体中文、日本語、한국어、English。
