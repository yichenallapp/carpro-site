愛車帳本 支援

遇到問題或有建議，先看看下面的常見問題；找不到答案再來信。

我的資料存在哪裡？

預設只存在你的 iPhone。你可以在「設定 → 同步方式」選擇同步到 iCloud 或你自己的 Google 試算表，也可以完全不同步。刪除 App 會一併刪除手機上的資料，所以想保留的話請先開啟同步。

換手機時怎麼把資料帶過去？

舊手機到「設定 → 同步方式」選 iCloud Drive（或 Google 試算表），等狀態顯示同步完成。新手機安裝 App，用同一個 Apple ID 登入並同樣選 iCloud Drive，車牌相同的車會自動合併，紀錄互相補齊。

免費版和 Pro 有什麼差別？

加油與花費紀錄、統計圖表、單位與幣別、多國語言永遠免費。Pro（一次性購買，不是訂閱）可以使用多台車與同步（iCloud、Google 試算表）。沒有 Pro 時紀錄只存在這支手機，之後解鎖 Pro 會自動補送，不會遺失。

怎麼還原購買或兌換優惠代碼？

到「設定 → Pro」按「還原購買」，用購買時的 Apple ID 就能找回；有優惠代碼的話按「兌換優惠代碼」。換手機、重灌 App 都用「還原購買」。若啟用家人共享，家庭成員也可以使用。

要怎麼同步到 Google 試算表？

App 內有逐步教學（第一次開啟的歡迎頁，或「設定 → 同步方式」旁的設定教學），約 5 分鐘。步驟是：建立試算表與分頁、貼上 App 提供的程式碼到 Apps Script、產生 API Token、部署為網頁應用程式，最後把網址與 Token 貼回 App。建議用電腦操作。

試算表分頁和表頭要怎麼命名？

支援繁體中文、English、简体中文三種，同一份表任選一種（英文不分大小寫）。例如英文：Fuel、Car Wash、Supplies、Maintenance、Insurance。App 的教學頁會依你的語言給出對應名稱與可複製的表頭。

測試連線顯示 unauthorized

Token 貼錯或有多餘文字，請重新複製一次。重新執行 setupToken 會產生新的 Token，舊的就失效。

顯示找不到分頁

分頁名稱要和範例一致（英文不分大小寫）。已有舊資料的試算表也可以直接用。

可以改單位和幣別嗎？

可以，到「設定 → 單位與幣別」。單位支援 km／L、L/100km、mpg（美制、英制），幣別有 18 種。這只改變顯示與輸入方式：資料一律以公里與公升儲存，已記錄的金額不會被換算。

可以記錄多台車嗎？

可以。每台車有自己的車牌、車型、領車日與領車里程；在首頁、紀錄、統計左上角的車牌按一下即可切換。多台車可以共用同一份試算表，用「車牌」欄區分。

平均油耗是怎麼算的？

用領車里程（或第一筆有里程的加油）到最後一筆里程的距離，除以期間加的油量。加油時有填里程才算得出來；也可以切換成「最近兩次加油」的油耗。

怎麼切換語言？

預設跟隨 iPhone 的系統語言，也可以在「設定 → 語言」手動選擇，重新開啟 App 後生效。支援繁體中文、简体中文、日本語、한국어、English。
